১. Component: অ্যাপ্লিকেশনের একটি স্বতন্ত্র এবং পুনরায় ব্যবহারযোগ্য অংশ (UI Block)।

উদাহরণ: একটি ওয়েবসাইটের 'Navbar' বা 'Footer' আলাদা কম্পোনেন্ট হতে পারে।

২. Component Types: মূলত দুই ধরণের—ফাংশনাল (আধুনিক ও জনপ্রিয়) এবং ক্লাস কম্পোনেন্ট (পুরানো)।

উদাহরণ: function Welcome() { ... } একটি ফাংশনাল কম্পোনেন্ট।

৩. JSX & its Rules: জাভাস্ক্রিপ্টের ভেতর HTML লেখার সিনট্যাক্স যা অবশ্যই একটি সিঙ্গেল প্যারেন্ট দিয়ে র‍্যাপ করা হতে হয়।

উদাহরণ: return ( <div> ... </div> ) এখানে div হলো প্যারেন্ট।

৪. Props: প্যারেন্ট থেকে চাইল্ড কম্পোনেন্টে ডাটা পাঠানোর মাধ্যম।

উদাহরণ: <User name="Arif" /> এখানে name একটি প্রপস।

৫. How to pass Props: কম্পোনেন্ট কল করার সময় অ্যাট্রিবিউট আকারে ডাটা পাঠিয়ে এবং চাইল্ডে আর্গুমেন্ট হিসেবে তা গ্রহণ করে।

উদাহরণ: ফাংশনের প্যারামিটারে (props) লিখে তা ব্যবহার করা।

৬. Read-Only Props: প্রপস সবসময় ইমিউটেবল বা অপরিবর্তনীয়; চাইল্ড চাইলে প্রপসের মান সরাসরি বদলাতে পারে না।

উদাহরণ: props.name = "New Name" লিখলে রিয়্যাক্ট এরর দেবে।

৭. Conditional Rendering: নির্দিষ্ট শর্তের ওপর ভিত্তি করে UI-তে ভিন্ন ভিন্ন এলিমেন্ট দেখানো।

উদাহরণ: ইউজার লগইন থাকলে 'Dashboard' দেখানো, নাহলে 'Login' বাটন দেখানো।

৮. Ternary Operator: condition ? true : false ফরম্যাটে ছোট আকারে শর্ত চেক করার পদ্ধতি।

উদাহরণ: {isLoggedIn ? <Logout /> : <Login />}।

৯. Map: একটি অ্যারে থেকে লুপ চালিয়ে প্রতিটি আইটেমকে আলাদা আলাদা কম্পোনেন্ট বা এলিমেন্ট হিসেবে রেন্ডার করা।

উদাহরণ: items.map(item => <li key={item.id}>{item.name}</li>)।

১০. Vite: একটি অত্যন্ত দ্রুতগতির আধুনিক বিল্ড টুল যা রিয়্যাক্ট প্রজেক্ট সেটআপ এবং রান করতে ব্যবহৃত হয়।
- উদাহরণ: npm create vite@latest দিয়ে প্রজেক্ট শুরু করা।

১১. Handle Event: camelCase পদ্ধতিতে ইভেন্ট লিসেনার যোগ করা (যেমন: onClick, onChange)।
- উদাহরণ: <button onClick={handleClick}>Click</button>।

১২. State Change: রিয়্যাক্টের 'স্টেট' আপডেট হলে কম্পোনেন্ট পুনরায় রেন্ডার হয়ে নতুন তথ্য স্ক্রিনে দেখায়।
- উদাহরণ: একটি কাউন্টার বাটনে ক্লিক করলে সংখ্যা বেড়ে যাওয়া।

১৩. useState Hook: ফাংশনাল কম্পোনেন্টে স্টেট বা ডাটা ধরে রাখার এবং আপডেট করার জন্য ব্যবহৃত হুক।
- উদাহরণ: const [count, setCount] = useState(0);।

১৪. React Hooks: বিশেষ ফাংশন যা ফাংশনাল কম্পোনেন্টে রিয়্যাক্টের স্টেট ও লাইফসাইকেল ফিচার ব্যবহারের সুযোগ দেয়।
- উদাহরণ: useState, useEffect

১৫. use Hook (New Concept): রিয়্যাক্টের নতুন একটি হুক যা প্রমিজ (Promise) বা কনটেক্সট থেকে ডাটা সরাসরি রিড করতে ব্যবহৃত হয়।
- উদাহরণ: const data = use(myPromise); (এটি এখনো পরীক্ষামূলক বা লেটেস্ট ভার্সনের অংশ)।

১৬. Dynamic Data Loading (API Call): বাইরের কোনো সার্ভার থেকে fetch ব্যবহার করে তথ্য নিয়ে এসে স্ক্রিনে দেখানো।
- উদাহরণ: JSONPlaceholder থেকে ইউজার লিস্ট নিয়ে আসা।

১৭. useEffect Hook: কম্পোনেন্ট রেন্ডার হওয়ার পর কোনো 'Side Effect' (যেমন: API কল বা সাবস্ক্রিপশন) হ্যান্ডেল করার হুক।
- উদাহরণ: পেজ লোড হওয়ার সাথে সাথে ডেটা ফেচ করা।

১৮. State Lifting Up: একাধিক চাইল্ডের মধ্যে ডাটা শেয়ার করার জন্য স্টেটকে তাদের কমন প্যারেন্ট কম্পোনেন্টে নিয়ে যাওয়া।
- উদাহরণ: দুই ভাই খেলনা শেয়ার করার জন্য সেটি বাবার কাছে রাখা।
